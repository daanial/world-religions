# Persian Wikipedia Translation & Verification Skill

This skill outlines the process and guidelines for validating Persian translations against standard academic Persian and Wikipedia conventions. It prevents transliteration errors for proper nouns that already have rich, historical, and standardized terms in Persian.

---

## 1. Core Principles

1. **Avoid Phonetic Transliteration for Established Terms:**
   * Do not transliterate names of figures, places, or concepts phonetically if they already have an established historical or religious translation in Persian culture.
   * *Example:* Use "عیسی ناصری" for "Jesus of Nazareth", not "جیسس ناصری". Use "بابل" for "Babylon", not "ببیلون".

2. **Verify Against Persian Wikipedia (`fa.wikipedia.org`):**
   * Use web searches or existing databases to cross-reference how Persian Wikipedia translates a specific tradition, concept, or historical figure.
   * Look for the exact title of the Wikipedia page in Persian (e.g., "نئوپیتاگوریسم" for "Neopythagoreanism" or "شینتو" for "Shinto").

3. **Academic and Encyclopedic Tone (نثر رسمی):**
   * Keep the register formal and written, matching the style of the *Encyclopaedia Islamica* or the *Encyclopedia of the World of Islam*.
   * Maintain epistemic hedging: translate "scholars argue" as "پژوهشگران بر این باورند" or "مورد بحث قرار می‌دهند" rather than presenting arguments as absolute facts.

4. **Consistency in Transliterating Non-Established Terms:**
   * For terms originating from indigenous traditions (e.g., Navajo *hózhó*, Yoruba *orisha*) that do not have standard Persian Wikipedia equivalents, transliterate the pronunciation carefully into Persian script and append the original Latin term in parentheses as a gloss on first use.

## 2. Common Translation Mappings Reference

Below is a verified list of standard translations matching Persian Wikipedia conventions for key terms:

* **Zoroastrianism:** دین زرتشت / مزدیسنا (Mazdayasna)
* **Manichaeism:** آیین مانی / مانویت
* **Gnosticism:** غنوصی‌گری / معرفت‌گرایی
* **Neo-Platonism:** افلاطونی نو / نوپلاطونی
* **Confucianism:** آئین کنفوسیوس
* **Daoism / Taoism:** تائویسم / آیین تائو
* **Shinto:** شینتو
* **Jainism:** جین‌بودا / آیین جین
* **Baha'i Faith:** بهائیت / آیین بهایی
* **Wicca:** ویکا
* **Slavic Paganism:** پاگانیسم اسلاوی

### Key Concepts
* **Reincarnation:** تناسخ / بازپیدایی
* **Enlightenment:** بیداری معنوی / اشراق
* **Sacred Geography:** جغرافیای مقدس
* **Pilgrimage:** زیارت / سفر زائران
* **Schism:** انشعاب / شقاق
* **Extinct Religion:** دین منسوخ / آیین تاریخی
