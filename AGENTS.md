# Repository translation rule

Never summarize or condense translated content. A translation must preserve every source paragraph, factual detail, example, date, number, named entity, qualification, disagreement, citation, link, key term, and source entry. Preserve the source structure and paragraph boundaries. If faithful translation is not complete, keep the module explicitly marked as a fallback or draft; never present a summary as a finished translation. Run `npx tsx scripts/check-fa-translation.ts` and complete sentence-level comparison before marking locale content done.
